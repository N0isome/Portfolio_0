# NChordtez — demo web

Compositor MIDI de Cortez Audio. Demo pública del proyecto Windows VST3 / standalone. Interfaz compacta con pestañas, 92 tipos de acordes, 36 estilos, 9 modos, pasos programables, MIDI Learn, dos FX y exportación SMF/MPE.

La demo usa Web Audio. No ejecuta el VST3 ni hospeda instrumentos nativos. La generación es estadística y basada en reglas, sin modelo neuronal. El binario Windows está compilado; no se certificó ejecución dentro de FL Studio.
